# SL-KernelSU 路线图

无时间承诺，只有顺序。上游能力盘点见 ADR-0008（A1/A4 已重新定义）。

## 里程碑

### M0 骨架（已完成 ✅ 2026-09-29）
- 本地骨架、ADR、roadmap、CI 骨架、主题 token 层 ✅
- 官方 KernelSU 源码就位（`upstream/`）✅ / 参考项目归档（`reference/`）✅
- Git 就位 + 本地仓库首次提交 ✅
- 工具链（JDK 21 / Android SDK / NDK / 自签密钥库）✅
- **Go/No-Go 门禁通过 ✅**：真机 `6.6.118-android15-8` 上由自编内核模块（注入自签证书指纹）接管 root；
  管理器 v0.0.5 内置 `.ko`，实现与其他分支一致的「直接安装 → 下一步」
- 待办：把上游源码正式并入仓库（形成完整 fork 结构）、多 KMI 构建矩阵

### M1 技术支点验证（注入点已核验，见 ADR-0008）
- A1 原型：两段式自动失败判定（启动标记 + 阈值禁用 + 下一轮 preinit rc 兜底）
- A4 增强原型：多轮启动日志留存（上游仅单轮）
- 产出：ADR-0003 转正或调整设计

### M2 MVP v0.1（零内核改动）
- A2 模块快照 + 一键回滚
- D1 日志中心 + 一键诊断包
- D2 授权增强（超时拒绝 / 授权记录 / 异常告警；安全红线见 ADR-0007）
- 主题 token 层落地（默认水色）

### M3 v0.2
- A1 自动安全模式正式版 + 管理器首页引导 + "一键安装 metamodule"
- A3 OTA 存活自动化（LKM 模式）
- 新手 / 专家模式分离（大众向必需）

### M4 v0.5
- **B3 模块备份导出 / 导入（自研，官方 KSU 无）**
- **B4 App Profile 扩展（自研，官方仅基础版）**
- 4 页视觉重构 + 樱粉皮肤包

### M5 v1.0
- SUSFS 内核线：按 KMI 用 DDK/CI 出内核模块与可选镜像（Tier A/B 分级）
- 发布工程：签名、更新通道、源码包（GPL 合规）、真机验证报告

## 功能优先级

| 优先级 | 功能 | 依赖 |
| --- | --- | --- |
| P0 | A1 自动安全模式（与上游手动 Safe Mode 协同，非从零） | ADR-0008 实现路径 |
| P0 | A2 快照回滚、A4 日志增强 | 无（用户空间） |
| P0 | D1 日志中心、D2 授权增强 | 无 |
| P1 | A3 OTA 存活、B3 备份、B4 App Profile 扩展 | LKM 模式 |
| P1 | 视觉：token 层 → 4 页重构 → 皮肤包 | ADR-0004 |
| P2 | Web 管理面板（可选、默认关、强鉴权）、D3 自检页、B2 模块仓库 | 安全评估先行 |
| P3 | SUSFS 内核线 | CI 内核流水线 |
| 不做 | E 组、改名重打包（U-C） | — |

## 发布分级（详见 ADR-0006）

- Tier A：CI 构建 + 真机验证（当前仅 `6.6-android15-8`）
- Tier B：仅 CI 构建，标注"实验性/未验证"，安装前强制防呆
